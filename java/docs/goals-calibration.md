# 自动比分模型校准报告

这是游戏平衡对照，不是对真实足球结果的拟合或预测验证。

数据：内置非自定义球队，完整首发且首发外场能力非全零，共 24 支；排除能力全零占位球队。首发门将中位数 28.0、平均值 30.375。模型基准门将 28.0。

每种模型遍历所有不同球队的有序对阵，每对 1000 场，种子 20260913。球队战术只排列首发前 11 人，不改变本次评分总和；门将取首发守门位置。

参数：门将倍率 exp(-0.4 × (value-28)/49)，主场倍率 1.08，90 分钟均值限制 [0.05, 5]；加时赛乘 30/90。0.4 与 1.08 是保守调校值，不是数据拟合系数。
